## Short description
Production-ready browser file toolkit where supported processing runs on the user's device instead of a file-processing backend. Includes image/PDF/audio tools, OCR, on-device background removal, PWA assets and a programmatic landing-page system. Pre-revenue; no meaningful marketing has been done.

---

## Long listing copy
ZeroUpload is a production-ready privacy-first browser utility platform for converting, compressing and editing files locally on the user's device.

The current product includes image conversion/editing, PDF conversion and management, browser-side audio conversion/editing powered by ffmpeg.wasm, OCR, and on-device AI background removal. The application is built with Astro, React and TypeScript and is deployed as a static site, so there is no customer database, authentication stack or server-side file-processing infrastructure to migrate.

The codebase also includes a data-driven landing-page architecture that generates dedicated static pages for supported conversion pairs and background-removal intents, plus supporting content and PWA/install assets.

The project is pre-revenue and has not received meaningful marketing or distribution. Usage to date has primarily been the owner and a small number of friends/testers. It is being sold as a finished software/IP asset and growth opportunity, not as an established revenue-generating business.

A buyer can keep the current concept, rebrand it, connect a custom domain, expand the tool catalog, pursue organic acquisition, add monetization or integrate the toolkit into a broader utility portfolio.

The sale is intended to include the application source code, Git history, seller-owned UI/product assets, existing content/landing-page system, PWA/deployment configuration and handoff documentation. Third-party libraries/models remain governed by their own licenses. No custom domain is currently included.
