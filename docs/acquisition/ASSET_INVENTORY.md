# ZeroUpload — Asset Inventory

## Included in a completed asset sale

### Software and source
- ZeroUpload application source code in this repository.
- Git history for the project repository.
- Astro/React/TypeScript application structure.
- Browser-side image, PDF, audio, OCR and background-removal implementations.
- Programmatic conversion-page and background-removal landing-page generation logic.
- PWA manifest and install assets.
- Cloudflare Pages-oriented deployment configuration and security headers.
- Existing written content and product copy contained in the repository.

### Product assets
- ZeroUpload name/branding assets to the extent owned and transferable by the seller.
- Icons, favicon, Open Graph image and interface assets contained in the repository.
- Current UI/UX implementation.

### Documentation
- Acquisition documentation under `docs/acquisition/`.
- Build/deployment instructions.
- Handoff notes.
- Sale-readiness automation and checks on the `sale-readiness` branch, if included in the final transferred repository state.

## Not included
- A custom domain: none is currently owned for the product.
- The seller's personal GitHub account.
- The seller's personal Cloudflare account.
- The seller's personal email accounts, authentication credentials, recovery codes or 2FA devices.
- Revenue, subscriptions or customer accounts: the product is pre-revenue.
- A customer database or mailing list: none is represented as part of the asset.
- Third-party software ownership. Third-party packages/models remain subject to their respective licenses.
- Exclusive rights to third-party trademarks, libraries, models or services.

## Transfer approach
The preferred transfer is the project repository/software assets to the buyer, followed by the buyer deploying the product in the buyer's own hosting account. Personal seller accounts should never be transferred.

## Final-sale note
The final asset purchase agreement should describe the precise transferred assets and any excluded assets. This document is an operational inventory, not a substitute for the final agreement.
