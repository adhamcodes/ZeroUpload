# ZeroUpload — Feature Matrix

## Core conversion tools

### Images
- PNG, JPG/JPEG, WEBP and supported raster conversions through browser APIs/Canvas.
- HEIC/HEIF decoding for supported output formats.
- Image compression.
- Image resizing.
- Image rotation/flip workflows.

### PDF
- PDF to image.
- Image to PDF.
- Merge PDFs.
- Split PDFs.
- Rotate PDF pages.
- Reorder/delete PDF pages.
- PDF compression.
- Extract text from PDF.

### Audio
- Conversion among MP3, WAV, OGG, M4A, FLAC and AAC.
- Trim audio.
- Merge audio.
- Compress audio.
- ffmpeg.wasm runs the processing in the browser.

### OCR
- Image-to-text extraction using browser-side OCR tooling.

### AI background removal
- On-device inference in the browser.
- No paid inference API is required for the current implementation.
- Model assets may be downloaded to the browser when needed; selected user images are processed locally.

## Product/platform features
- Static Astro application.
- React interactive components.
- TypeScript codebase.
- Tailwind CSS styling.
- Installable PWA metadata/assets.
- Cloudflare Pages deployment compatibility.
- Security/cache headers configured for the static host.
- No account required for users.
- No customer database.
- No server-side file-processing queue.
